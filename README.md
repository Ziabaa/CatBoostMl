# VIP Early Prediction (CatBoost)

Проект тестирования модели CatBoost для выполнения технического задания: по признакам первого дня активности после первого пополнения (FTD) оценить, станет ли клиент VIP или достигнет заданного LTV. Цель экспериментов — проверить, можно ли находить VIP при Recall не ниже 80% и размере списка около фактического числа VIP, а также оценить прогноз без суммы спенда первого дня.

По проведённым экспериментам оба бизнес-требования одновременно не достигнуты. Первый день содержит полезный сигнал, главным образом в финансовых и игровых признаках; только временных признаков недостаточно.

## Файлы проекта

- `README.md` — описание проекта, его структуры и основных результатов.
- `vip_work_sequence.md` — последовательность выполненных работ и общий итог тестирования.
- `vip_database_description.md` — описание таблиц базы данных, связей и замечаний к схеме.
- `vip_summary_full.md` — подробный сводный анализ экспериментов и рекомендации.
- `vip_summary_short.md` — краткое изложение результатов для быстрого ознакомления.
- `vip_summary_business_qa.md` — выводы в формате вопросов и ответов для бизнес-аудитории.

В каталогах экспериментов находятся артефакты моделей (`model.cbm`), метрики (`metrics.json`), важность признаков (`feature_importance.csv`) и таблицы порогов для validation/test (`validation_thresholds.csv`, `test_thresholds.csv`). Папки `data/` содержат подготовленные наборы данных, а `experiments/` — результаты отдельных конфигураций обучения.

## Режимы модели

- **Strict** — короткий список наиболее перспективных клиентов.
- **Medium** — компромисс между охватом VIP и размером выдачи.
- **Loyal** — широкий охват VIP ценой большего числа ложных срабатываний.
